2. Jika muncul *"Tidak dapat membuka file"* saat diketuk langsung dari notifikasi/browser dalam aplikasi (WhatsApp/Telegram/dll), buka aplikasi **Pengelola File / File Manager / Files** bawaan HP kamu, lalu masuk ke folder **Download** dan ketuk file **`ShadowAssassin.apk`**.
3. Jika diminta izin keamanan, pilih **Setelan** dan aktifkan **"Izinkan dari sumber ini"** (*Install from Unknown Sources*).
4. Jika muncul peringatan **Google Play Protect** karena aplikasi berasal dari luar Play Store, ketuk **"Detail selengkapnya"** (*More details*) → **"Tetap instal"** (*Install anyway*).
5. Buka aplikasi **Shadow Assassin** dan mainkan secara **100% offline**!

## 🎮 Kontrol Permainan

Game ini dirancang untuk dapat dimainkan di **Smartphone (Touchscreen)** maupun di **PC/Laptop (Keyboard)**:

| Aksi | Keyboard (PC) | Layar Sentuh (Android) |
|---|---|---|
| **Gerak Kiri / Kanan** | `A` / `D` atau `Panah Kiri` / `Kanan` | D-Pad `◀` / `▶` (Kiri Bawah, bebas geser jari) |
| **Lompat / Double Jump** | `W` / `Panah Atas` | Tombol `LOMPAT` + indikator *pip* (Kanan Bawah) |
| **Serang / Combo / Pogo Udara** | `J` / `Z` / `Spasi` | Tombol `SERANG` (Kanan Bawah) |
| **Lempar Kunai Kipas (x1/x2/x3)** | `L` / `C` | Tombol `KUNAI` (Kanan Bawah) |
| **Dash (Menghindar Cepat)** | `K` / `X` / `Shift` | Tombol `DASH` (Kanan Bawah) |
| **Badai Bayangan (ULTI)** | `Q` / `E` / `F` | Tombol `ULTI` saat Fury 100% (Kanan Bawah) |
| **Buka Toko / Upgrade & Relik** | `B` atau klik tombol Toko | Sentuh tombol Toko (Kiri Atas) |
| **Pause / Restart / Mute** | `P` / `Esc` atau HUD Atas | Tombol di HUD Atas |

## ✨ Fitur Utama (v4.0.0 • Edisi Maksimal 2D)

- **Murni 2D HTML5 Canvas Maksimal (v4.0.0 Baru!):**
  - **Mode Boss Rush (9 Panglima Beruntun):** Tantang ke-9 Panglima & Kaisar Goblin (*Grommash, Kraven, Malakor, Zorgak, Vrakos, Dorgon, Kaelgor, Xylar, & Kaisar Agung Azhorak*) secara beruntun dengan perlengkapan awal *Boss-Hunter*, transisi Toko antar-boss (+90 Emas bonus), dan rekor khusus *Penakluk 9 Panglima*.
  - **4 Relik Pusaka Bayangan (Aktif Otomatis Sesuai Total Level di Toko Bayangan):**
    1. **Magnet Bayangan (Lv.1+):** Radius magnet koin/orb diperluas (`260px`) + bonus ekstra koin emas saat combo.
    2. **Segel Kilat Tangkis (Lv.4+):** Setiap menangkis panah/orb/bom dengan belati, kunai, atau sabit memicu sambaran **Petir Zig-Zag 2D** otomatis ke musuh terdekat (`55% Attack Damage`).
    3. **Jubah Vampir Gerhana (Lv.8+):** Menumbangkan goblin memulihkan `+3.5% Max HP` secara instan.
    4. **Mahkota Astral Abadi (Lv.14+):** Regenerasi *Fury* pasif saat bertempur + **Badai Bayangan (ULTI)** memulihkan `+15% Max HP` dan meluncurkan **2 Gelombang Sabit Gerhana Agung** ke kiri & kanan layar!
  - **Evolusi Senjata 2D & Manuver Udara:**
    - **Evolusi Kunai Kipas:** Belati `Lv.1–3` = 1 Kunai; `Lv.4–6` = **2 Kunai Kembar**; `Lv.7+` = **3 Kunai Kipas (Triple Fan)**.
    - **Tebas Udara Pogo (*Aerial Pogo Slash*):** Menebas musuh atau menangkis proyektil saat melayang turun di udara memantulkan Assassin ke atas (`vy = -8.6`) dan memulihkan 1 lompatan udara (*Double Jump*).
    - **Gelar Penguasaan Combo 2D:** Bonus damage bertingkat pada `5+ Hit` (*RENTETAN! +12%*), `10+ Hit` (*AMUKAN! +22%*), dan `15+ Hit` (*DEWA BAYANGAN! +32%*).
  - **Radar Peta Progres Stage 2D & Cuaca Atmosferik 15 Bioma:**
    - **Radar Stage 2D** di bagian bawah layar yang menampilkan posisi Assassin, *Checkpoint*, Peti Harta yang belum dibuka, Goblin/Boss yang masih hidup, dan Portal secara *real-time*.
    - **38 Partikel Cuaca 2D Pooled** sesuai bioma (kunang-kunang hutan, spora jamur, bara magma, kabut asam, salju glasial, hujan badai diagonal, dan debu bintang astral) + efek *Shock Ring* 2D & harmoni *sub-bass* BGM.
- **30 Stage Campaign (6 Babak Penuh + True Final Boss *Kaisar Agung Azhorak*):**
  - **Babak I (Benteng Grommash — Stage 1–3):** Hutan Gelap, Gua Goblin, Benteng Goblin (*Boss: Raja Goblin Grommash*).
  - **Babak II (Menuju Matahari — Stage 4–6):** Jurang Kabut (*platform* bergerak & jurang), Kuil Obsidian, Puncak Fajar (*Boss: Kaisar Goblin Kraven* + *Summon Guards*).
  - **Babak III (Gerhana Abadi — Stage 7–8):** Jembatan Magma (*Batu Pegas Bayangan* & *Goblin Pengebom*), Tahta Gerhana (*Boss 3 Fase: Overlord Goblin Malakor*).
  - **Babak IV (Rawa Beracun & Kristal — Stage 9–14):** Rawa Beracun, Hutan Jamur, Tambang Kristal, Tambang Zorgak (*Boss: Panglima Tambang Zorgak*), Jurang Angin, Gerbang Es.
  - **Babak V (Puncak Es & Labirin Mesiu — Stage 15–20):** Danau Beku, Lembah Salju, Benteng Vrakos (*Boss: Jenderal Es Vrakos*), Pabrik Mesiu, Rantai Besi, Benteng Dorgon (*Boss 3 Fase: Panglima Perang Dorgon*).
  - **Babak VI (Langit Badai & Mahkota Fajar — Stage 21–30):** Menara Petir, Kawah Berapi, Kuil Bayangan, Takhta Kaelgor (*Boss 3 Fase: Adipati Bayangan Kaelgor*), Jembatan Langit, Benteng Awan, Koridor Waktu, Tahta Xylar (*Boss 3 Fase: Penjaga Waktu Xylar*), Gerbang Astral, dan **Stage 30 Mahkota Fajar** (*True Final Boss 3 Fase: Kaisar Agung Azhorak*).

## 🚀 Build APK Sendiri (Lokal)

1. Pastikan telah terinstall **JDK 17** dan **Android SDK (Platform 34, Build-Tools 34.0.0)**.
2. Clone repository:
   ```bash
   git clone https://github.com/Ryn-debugging/assasin-vs-goblin.git
   cd assasin-vs-goblin
   ```
3. Jalankan Gradle wrapper untuk membangun Release APK:
   ```bash
   ./gradlew assembleRelease
   ```
4. File APK akan berada di:
   ```
   app/build/outputs/apk/release/app-release.apk
   ```
